# Claude launcher maintenance

`tools/claude-launcher.sh` preserves the installed launcher selection and exact argument forwarding while removing the obsolete exclusive-coordinator key check. It does not select a model, alter login, send a signal or restart a process itself. Agent lifecycle remains subject to the generated rules and active work claims.

Install only the exact reviewed file from canonical main through the existing protected-file updater. Keep the previous protected copy as the undo. Before updating, record the operator authorization and undo on the board and obtain a successful one-shot answer through the candidate launcher. Verify installed bytes against canonical main afterward. The destination is machine-specific and belongs in the private installation receipt.

The live executable selection is inherited from the existing launcher; it selects the greatest version directory lexically with version ordering. This change does not upgrade or remove Claude.
